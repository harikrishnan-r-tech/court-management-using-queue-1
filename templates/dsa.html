🔃 6. Bubble Sort — Used in All Cases table O(n²) avg · O(n) best

Bubble Sort repeatedly compares and swaps adjacent elements. Used to sort the All Cases table by Case ID, Priority, or Filing Date. Implemented in dsa/sorting.py. 

for i in range(n):            # O(n) passes
    for j in range(0, n-i-1): # O(n) comparisons per pass
        if key(arr[j]) > key(arr[j+1]):
            arr[j], arr[j+1] = arr[j+1], arr[j]  # swap
    if not swapped: break     # O(n) best case
🔍 7. Searching Algorithms

Linear Search — O(n)

Scans every case one by one. Works on any list.

for case in cases:
    if query in case[field]:
        return case

Binary Search — O(log n)

Sorted list; halves search range each step.

low, high = 0, n-1
while low <= high:
    mid = (low+high)//2
    if arr[mid] == target: return

Hash Lookup — O(1) avg

Python dict. Direct key access via hash function.
